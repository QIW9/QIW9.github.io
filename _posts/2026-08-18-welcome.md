这里是我的第一篇文章。博客使用 [Jekyll](https://jekyllrb.com/) 构建，托管在 GitHub Pages 上，支持完整的 Markdown 渲染。

## 如何写文章

在 `_posts` 目录下新建一个文件，命名为 `YYYY-MM-DD-标题.md`，并添加头部信息：

```markdown
---
layout: post
title: 文章标题
date: 2026-08-18
---

正文内容……
```

## 支持的 Markdown 语法

- **加粗** 和 *斜体*
- `行内代码`
- [链接](https://github.com)
- 引用：

  > 简单即美。

- 列表：
  1. 第一条
  2. 第二条

提交到 GitHub 的 `master` 分支后，GitHub Pages 会自动构建并发布。
